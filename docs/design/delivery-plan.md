- 排期原则(已确认):**项目收口前(2026 年 9 月初)四条核心能力全部落地**;目标日期按此倒排,允许微调,不允许里程碑降级砍验收。
- 各专项设计以对应文档为准,本文不重复字段与协议细节;实现进度在 [`../roadmap.md`](../roadmap.md) 打勾,验收未过不得标记完成。

  以"统一响应 + 路由分组 + 中间件挂载点 + AutoMigrate/启动期数据修复"作为 M1 的前置落地。M1/M2 全部验收已通过,见 [`../notes/压测报告.md`](../notes/压测报告.md)。

## 交付原则

- **先闭环,再扩展**:每个里程碑交付一条能真实运行、可验证、可讲述的纵向链路,不并行铺空壳。
- **产出即验收**:对外承诺的每个数字与每个机制,完成后都必须有代码、文档或压测记录作为出处。
- **目标与现状分开**:未完成的能力不得在任何文档或对外表述中描述为已有。
- **深度优先**:遇到排期冲突,砍范围(推迟远期项)不砍质量(验收标准)。

## M0:工程化基础(→ 8/03)

### 工作内容

1. `internal/bootstrap`:唯一装配点,消灭业务包副作用 `init()`;service / controller 显式持依赖;逆序优雅关闭(移除"清空 Redis 全库"行为)。
2. 统一响应与错误码:`code/message/data`、错误类型、全局错误中间件;废止 `ret` 约定;`BindJSON` 失败归为参数错误。
3. 路由:`/api/v1` 前缀 + 模块分组 + 中间件挂载点(鉴权位留空);前端同步切 baseURL。
4. golang-migrate:基线迁移 `000001` + `user_contact` 清重与联合唯一索引 `000002`。
5. `user_contact` 行生命周期统一:关系建立改 upsert(复用旧行),废除关系行软删除,全部语义走 `status`(先改代码,再跑 `000002`,见 database.md)。

### 完成标准

- 全仓 `grep` 无业务包 `init()` 装配;`main` 只调 bootstrap。
- 任一接口的成功 / 参数错误 / 系统错误响应符合 api.md 契约;前端全功能回归可用。
- 空库仅靠迁移链可建出完整可运行环境;`migrate down` 可回滚。

## M1:鉴权与账号安全(→ 8/17)【核心能力 1】

### 工作内容

1. bcrypt 哈希 + 存量明文透明升级(database.md `000003`/`000004` 迁移,含手机号唯一索引)。
2. JWT 双 Token:签发、续期旋转、登出撤销、Redis 白名单、登录失败限流(api.md 契约)。
3. 鉴权 / 管理员中间件;全部接口身份改从 context 读取,废弃请求体身份字段。
4. WS 握手鉴权(query token),`client_id` 废弃;连接断开写 `last_offline_at`,登录写 `last_online_at`。

### 完成标准

- 未带 token 访问受保护接口返回 401;伪造他人 `uuid` 的请求体字段不再生效(有测试)。
- Access 过期后前端无感续期成功;Refresh 旋转重放触发全量撤销(有测试)。
- 管理员禁用用户后:15 分钟内其 Access 失效、Refresh 立即失效、在线 WS 被断开。
- 数据库中无明文密码新增;登录一次后存量账号密码变为哈希。

## M2:消息管道与性能(→ 8/29)【核心能力 2、3】

### 工作内容

1. 下行降级:SendBack 非阻塞写 + 丢弃计数 + 慢客户端断开;上行拒绝回写改走单写者;连接生命周期与 channel 关闭权重写;心跳(messaging.md)。
2. 自研 Go WS 压测客户端:并发拨号、速率控制、端到端延迟打点、慢客户端注入。
3. 压测四场景(在线规模 / 稳态延迟 / 群聊风暴 / 慢客户端),结果与机器配置记录入仓。
4. 缓存验证:高频接口命中率与失效一致性实测;记录响应时间与 DB 查询量对比数据。

### 完成标准

- 慢客户端注入下:全局吞吐无劣化,慢连接按阈值被断开,重连拉取补齐(压测可复现)。
- 每条降级路径(上行拒绝、下行丢弃、超限断开)至少被压测真实触发一次并有日志/计数为证。
- 产出替换对外数字的实测报告:并发连接数、P50/P99 延迟、缓存前后对比;文档同步更新为实测值。

## M3:AI 助手(→ 9/07)【核心能力 4】

### 工作内容

1. 机器人账号 seed 迁移 + 自动建联系人;AI SSE 端点(ai-assistant.md 契约)。
2. Eino ReAct Agent + 三工具(Serper 搜索 / 文件总结 / 文本扩写);StepFun OpenAI 兼容接入(凭据配置化)。
3. 前端机器人会话:发送走 AI 端点、SSE 渲染、工具状态提示。

### 完成标准

- 三个工具各有一条可复现演示用例(录屏或脚本)。
- 断流取消、超时、并发超限、模型故障四条失败路径真实触发验证;AI 完全不可用时 IM 主链路零影响。
- 回复落库为普通消息,历史拉取、last_message 展示正确。

## 里程碑外(明确推迟)

RESTful 全量重构、送达/已读回执、群成员拆表、MinIO、RBAC/Keycloak、多实例分布式——全部记为远期,不占 9 月前排期。

- 里程碑内变更范围需回到对应设计文档改决策,再改计划;不允许"先做了再补文档"。
